# 畳業界の専門知識ベース

## 1. 畳の基本構造

### 畳の3つの構成要素
1. **畳床（たたみどこ）** - 芯材
   - ワラ畳床：天然稲わらを圧縮したもの（伝統的）
   - ワラサンド：断熱材を稲わらで挟んだもの
   - 建材畳床：ポリスチレンフォーム+インシュレーションボード（現代主流）
   - 寿命：約30年

2. **畳表（たたみおもて）** - 表面材
   - 天然い草表：伝統的な天然素材、香りが良い
   - 紙素材表（ダイケン和紙表）：機械すき和紙を使用
   - ポリプロピレン素材表（セキスイ美草）：樹脂製、耐久性が高い

3. **畳縁（たたみべり）** - 縁の装飾布
   - 畳表を保護し、装飾性を高める
   - 角の保護と隙間を埋める衛生的な役割

## 2. 畳の種類

### 縁の有無による分類
- **縁付き畳**
  - 一般的な畳、格式が高く荘厳な雰囲気
  - 住宅、寺社仏閣で使用
  
- **縁なし畳（琉球風畳）**
  - 縁がなくすっきりした見た目
  - 半畳サイズで市松模様に配置
  - ※注意：本来の琉球畳は沖縄産のい草を使用したもの。現在一般的に「琉球畳」と呼ばれているものは「琉球風畳」が正確

### 厚さによる分類
- **通常畳**：厚さ55-60mm
- **薄畳**：厚さ15-30mm（バリアフリー、洋室用）
- **置き畳**：通常の半分程度、フロア畳・ユニット畳

## 3. 畳の工法と価格相場

### 3つの工法
**重要注意事項：価格は各店舗によって大きく異なります。以下は参考価格であり、高い傾向があります。**

#### 新調工事（しんちょうこうじ）
- **内容**：畳床・畳表・畳縁をすべて新しくする
- **価格相場**：15,000円〜25,000円/畳（店舗により異なる）
- **推奨時期**：15年〜20年経過後
- **工期**：1日〜2日
- **注意**：畳表・畳床の品質によって価格と寿命が大きく変わる

#### 表替え（おもてがえ）
- **内容**：畳表と畳縁を新しくする（畳床はそのまま）
- **価格相場**：8,000円〜15,000円/畳（店舗により異なる）
- **推奨時期**：7年〜10年経過後（または裏返し後5年）
- **工期**：半日〜1日
- **注意**：畳表の品質によって価格と寿命が大きく変わる

#### 裏返し（うらがえし）
- **内容**：畳表を裏返して再利用（畳床・畳縁はそのまま）
- **価格相場**：5,000円〜8,000円/畳（店舗により異なる）
- **推奨時期**：3年〜5年経過後
- **工期**：半日
- **注意**：い草表のみ可能（紙素材・ポリプロピレン素材表は不可）

### 価格に影響する要因
1. **素材の品質**
   - **国産い草 vs 中国産い草**
     - 中国産畳表：国産下級品の約2/3が一般的（店舗により差あり）
     - 一部では半額程度のケースもある
     - ※奥井畳店では中国産は扱わず
   - **化学表（紙素材・ポリプロピレン素材）と天然い草の価格差**
     - 化学表は天然い草下級品の1.5倍〜2倍の価格
   - 畳床の種類（ワラ床 vs 建材床）

2. **地域差**
   - 都市部は高い傾向
   - 地方は比較的安価
   - 関西間サイズ（京間）と関東間サイズで価格差がある

3. **店舗によるサービス差**
   - 施工品質、アフターサービス
   - 材料の仕入れルート
   - 国産専門店 vs 中国産も扱う店

## 4. 新素材畳表（化学表）の特徴

### ダイケン和紙表（健やかおもて）
**素材**：機械すき和紙（紙素材）

**メリット**
- 天然い草に近い見た目と質感
- 日焼けや退色に強い
- カビやダニが発生しにくい
- 耐久性が高い（い草の約3倍）
- 色柄が豊富
- 撥水性がある

**デメリット**
- い草の香りがない
- 天然素材に比べて価格が高い傾向

**推奨用途**
- アレルギー対策が必要な家庭
- ペットを飼っている家庭
- 頻繁に掃除が必要な場所

### セキスイ美草（MIGUSA）
**素材**：ポリプロピレン+無機材料（ポリプロピレン素材）

**メリット**
- 色あせしにくい
- 非常に丈夫で耐久性が高い
- 水拭きが可能
- カビやダニに強い
- カラーバリエーションが豊富

**デメリット**
- い草の香りがない
- 日焼けしにくいため汚れが目立ちやすい
- 価格が高い傾向

**推奨用途**
- 店舗、飲食店
- 介護施設、旅館
- デザイン性を重視する空間

### 化学表の選び方の注意点
**重要**：化学表（紙素材・ポリプロピレン素材表）については、正しい商品認知がまだされていません。必ず畳店に直接相談し、商品を精査する必要があります。

### ダイケン和紙表 vs セキスイ美草の選び方

**比較ポイント**
- **耐久性**：セキスイ美草の方が丈夫な傾向
- **見た目**：ダイケン和紙表の方が天然い草に近い
- **用途別推奨**
  - セキスイ美草：車椅子での移動、子供が乱暴に扱う、商業施設
  - ダイケン和紙表：天然素材に近い見た目を重視、住宅用

### 化学表を選ぶべき顧客の特徴
以下のいずれかに該当する場合、化学表（紙素材・ポリプロピレン素材表）を推奨：
1. **湿気が多い部屋**：カビが発生しやすい環境
2. **子供が乱暴に扱う**：耐久性が必要
3. **車椅子で部屋を移動**：摩擦に強い素材が必要
4. **い草の匂いが苦手**：香りのない素材を希望
5. **カラーバリエーションが欲しい**：デザイン性を重視

### 化学表を選ぶべきでない顧客の特徴
以下のいずれかに該当する場合、天然い草を推奨：
1. **天然素材が好き**：自然素材へのこだわり
2. **底冷えを気にする**：天然い草の方が保温性が高い
3. **調湿効果を期待**：天然い草の湿度調整機能を求める
4. **香りを求める**：い草の香りでリラックスしたい
5. **フィトンチッド効果を期待**：天然い草の抗菌・消臭効果を求める

## 5. よくある畳の症状と対策

### 症状1：靴下にい草のささくれがつく
**原因**
- 畳表の劣化、い草の繊維が傷んでいる
- 使用年数が長い（5年以上）

**対策**
- **基本は表替え**を推奨
- **前回の畳替えから5年以内の場合**：裏返しの可能性あり
- 緊急対応：掃除機で丁寧に吸引

**診断**：表替えまたは裏返しの時期

### 症状2：シミが気になる
**原因**
- 飲み物をこぼした跡
- カビによる変色
- 日焼けによる変色

**対策**
- 軽度：固く絞った雑巾で拭き取り
- 中度：専用クリーナーを使用
- **重度：表替えを推奨**

**診断**
- **基本は表替えで対応可能**
- **ただし畳床にシミがありカビが発生している場合**：新調工事の可能性あり

### 症状3：畳が沈み込む
**原因**
- 畳床の劣化
- 湿気による畳床の変形

**対策**
- 畳床の状態確認が必要
- 重度の場合は新調工事を推奨

**診断**：新調工事の時期
- **新調工事の目安**：1畳あたり2箇所以上沈み、他の畳にも症状が広がっている場合

### 症状4：カビが発生している
**原因**
- 湿気が多い環境
- 換気不足
- 結露

**対策**
- 換気を徹底する
- 除湿器の使用
- カビ取り剤で除去
- 重度の場合は表替え検討

**診断**：環境改善+表替え検討
- **表替えで解決するかは畳床のカビ具合次第**
- **干すことで解決する場合もある**
- **畳床が重度にカビている場合**：畳床の交換（新調工事）が必要

### 症状5：ダニが気になる
**原因**
- 湿度が高い
- 掃除不足
- い草の中にダニが繁殖

**対策**
- 掃除機を丁寧にかける
- 換気と除湿
- ダニ対策スプレー
- 新素材畳表（紙素材・ポリプロピレン素材表）への交換検討

**診断**：表替え+新素材表検討
- **表替えだけで解決するかは畳床の種類次第**
  - **建材床の場合**：繁殖空間がないとされる
  - **建材床でクッション材がある場合**：クッション材に繁殖する可能性あり
  - **ワラ床の場合**：ダニが繁殖しやすい構造

### 症状6：変色・日焼け
**原因**
- 紫外線による退色（天然い草）
- 経年劣化

**対策**
- カーテンやブラインドで直射日光を防ぐ
- 新素材畳表（日焼けに強い）への交換検討

**診断**：表替えの時期、または新素材表への変更

## 6. 畳のメンテナンス目安

### 時期別の推奨作業
**注意**：畳表・畳床の品質によって年数は大きく変わります。以下は一般的な目安です。

| 経過年数 | 推奨作業 | 理由 |
|---------|---------|------|
| 2〜3年 | 裏返し | い草表の裏面はまだ綺麗 |
| 3〜5年 | 裏返し（未実施の場合） | 表面の劣化が進む前に |
| 5〜7年 | 表替え | 両面とも劣化している |
| 7〜10年 | 表替え（裏返し後） | 畳床は問題なし |
| 10〜15年 | 表替えまたは新調検討 | 畳床の状態次第 |
| 15年以上 | 新調工事 | 畳床の寿命 |
| 30年以上 | 必ず新調工事 | 畳床の限界 |

### 日常のお手入れ
1. **掃除機**：畳の目に沿ってかける（週1回）
2. **乾拭き**：固く絞った雑巾で拭く（月1回）
3. **換気**：定期的に風を通す（毎日）
4. **直射日光を避ける**：カーテンやブラインドを使用

## 8. 営業・提案のポイント

### 顧客のニーズ別提案
1. **コストを抑えたい顧客**
   - 裏返しを提案（可能な場合）
   - 中国産い草表の表替え
   - 複数の選択肢を提示
   - **重要**：安かろう悪かろうを避け、長期視点を持つよう助言

2. **品質重視の顧客**
   - 国産い草表（熊本産など）
   - 新素材畳表（ダイケン、セキスイ）
   - ワラ畳床の新調工事

3. **アレルギー対策**
   - 新素材畳表（紙素材・ポリプロピレン素材表）
   - ダニ・カビに強い素材
   - 換気とメンテナンスのアドバイス

4. **デザイン重視の顧客**
   - 縁なし畳（琉球風畳）
   - カラー畳（セキスイ美草）
   - 薄畳（洋室との調和）

### アップセル戦略（売上向上のポイント）
以下を提案することで売上向上が可能：
1. **機能シート**：防音・断熱・防カビシート
2. **撥水加工**：汚れ防止、お手入れ簡単
3. **有料の畳縁**：デザイン性の高い装飾縁
4. **複数箇所同時施工**：割引適用で満足度向上

### 顧客が迷っている時の決断促進
- **畳替えは長い買い物**：10年単位での投資であることを強調
- **信頼関係の構築**：専門知識と誠実な対応で信頼を得る
- **実績の提示**：過去の施工事例や顧客の声を共有
- **タイミングの重要性**：症状が悪化する前の対応を推奨

### 見積もりだけの顧客への対応
- **知識提供を重視**：見積もり時に畳の基礎知識を丁寧に伝える
- **将来的な顧客獲得**：口コミで新規顧客を呼ぶ可能性を意識
- **プロとしてのアドバイス**：押し売りせず、適切な提案を行う
- **長期的な関係構築**：今回は見積もりでも、次回以降の依頼につなげる

### 説明時の注意点
1. **専門用語は必ず説明する**
   - 「表替え」「裏返し」「新調工事」の違い
   - 「畳床」「畳表」「畳縁」の役割

2. **価格は幅を持たせて説明**
   - 「店舗によって異なります」を必ず伝える
   - 「品質によって価格が変わります」を強調
   - 高い傾向があることを事前に伝える

3. **メンテナンス時期は目安として伝える**
   - 「品質によって年数は大きく変わります」を明記
   - 実際の状態を見て判断することを推奨

4. **新素材畳表は慎重に説明**
   - 正しい商品認知がまだされていない
   - 必ず畳店に直接相談することを推奨
   - メリット・デメリットを公平に説明

## 9. 業界の暗黙知

### 言ってはいけないこと（タブー）
- 「この畳はすぐにダメになります」（ネガティブすぎる）
- 「絶対にこの素材がいいです」（押し売り感）
- 「他の店より絶対安いです」（価格競争は避ける）
- **他店の批判**：絶対に避けるべき

### よくある勘違い
1. **琉球畳 = 縁なし畳**
   - 正確には「琉球風畳」が正しい
   - 本来の琉球畳は沖縄産い草を使用

2. **裏返しは何度でもできる**
   - 実際は1回のみ（裏面も劣化するため）
   - 新素材畳表は裏返し不可

3. **裏返し = 畳をそのままひっくり返す**
   - 実際は畳表を剥がして裏返す作業

4. **畳表の種類は1つだけ**
   - 実際は多数の品種・品質・産地がある

5. **新素材畳表は完璧**
   - メリットは多いが、い草の香りがない
   - 価格が高い傾向
   - 必ず畳店に相談して選ぶべき

6. **畳床は永遠に使える**
   - 実際は約30年が寿命
   - 15年以上経過したら新調検討

### 差別化ポイント（他社との違いを出す方法）
1. **専門知識の提供**
   - 畳の状態を正確に診断
   - 顧客のニーズに合った提案

2. **アフターサービス**
   - 施工後のフォロー
   - メンテナンスのアドバイス

3. **地域密着**
   - 地域の気候に合った提案
